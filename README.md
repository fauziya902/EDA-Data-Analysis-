# 📊 Exploratory Data Analysis (EDA) – World Ranking University

## 📌 Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a World University Ranking dataset to understand trends, patterns, and key factors influencing university rankings globally. The analysis helps in gaining meaningful insights from raw data through statistical and visual techniques.

---

## 🎯 Objective
The objective of this project is to apply Exploratory Data Analysis techniques to:
- Understand the structure and quality of the dataset
- Identify patterns, trends, and correlations
- Extract actionable insights from educational ranking data

---

## 📂 Dataset
- World University Ranking dataset  
- Contains information such as university name, country, ranking score, and performance indicators

---

## 🛠️ Technologies & Tools Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Jupyter Notebook  

---

## 🔍 Key Analysis Performed
- Data cleaning and handling missing values  
- Descriptive statistical analysis  
- Correlation analysis between ranking factors  
- Data visualization using charts and graphs  
- Comparative analysis across countries and institutions  

---

## 📈 Insights & Findings
- Identified key metrics that significantly impact university rankings  
- Observed trends in top-ranking universities across different countries  
- Analyzed relationships between ranking score and performance indicators
